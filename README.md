# Tools

A collection of utility scripts and automation tools for managing development projects.

## Overview

This repository contains reusable scripts across multiple languages and technologies:

- **Python**: General-purpose scripting and automation
- **TCL**: EDA tool automation and hardware design workflows
- **Make**: Build systems and task orchestration
- **Shell**: System-level operations and integration
- **Other**: Miscellaneous tools in other languages

## Quick Start

See [context.md](./context.md) for detailed information about repository structure and conventions.

## Getting Started

1. Browse the relevant category for your use case
2. Check individual script documentation
3. Review dependencies listed in comments or requirement files
4. Run with appropriate interpreter/tool
